AEX-128: A Key-Dependent Finite-State SPN–ARX Hybrid Block Cipher

M. Alawida, M. L. Menber

IEEE Access, 2026 — doi: 10.1109/ACCESS.2026.3730739

A 128-bit hybrid block cipher whose round structure is governed by a key-dependent finite-state machine with 59,049 possible execution paths. Security evaluation includes MILP-based active S-box analysis (36 active S-box minimum), SAC testing with chi-square analysis, and NIST SP 800-22 statistical testing.
